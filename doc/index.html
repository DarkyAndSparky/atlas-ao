Документация

Атлас Аллодов — самостоятельный сайт-энциклопедия аллодов (островов) вселенной Allods Online: глобальная карта, вики-каталог, страницы островов с историей и галереей, встроенный редактор для наполнения. Работает локально на вашем компьютере, без внешних сервисов.

Версия v26w31-12 Node.js 22.5+ Без сети — всё локально

Что это такое

Атлас — это одновременно и карта, и вики-справочник по островам-аллодам. Глобальная карта — визуальная надстройка поверх текстового каталога «Атлас островов»: оба показывают одни и те же данные и ссылаются на одни и те же страницы островов, просто по-разному их организуют.

Данные хранятся в локальной базе SQLite на вашем компьютере. Наполнять и редактировать их можно прямо на сайте — отдельный установочный редактор или консоль не требуются.

Быстрый старт

Через скрипты (рекомендуется)

Windows: дважды кликните install.bat один раз, затем start.bat каждый раз, когда хотите открыть сайт.

Linux / macOS:

chmod +x install.sh start.sh   # один раз
./install.sh
./start.sh

Браузер откроется автоматически на http://localhost:4173.

Вручную

cd server
npm install
node server.js

Системные требования

  • Node.js 22.5 или новее — сайт использует встроенный node:sqlite, поэтому отдельная СУБД или компиляция нативных модулей не нужны.
  • Любой современный браузер (Chrome, Firefox, Safari, Edge).
  • Сеть не требуется — сайт полностью локальный, обращений во внешний интернет во время работы нет (кроме шрифтов, если вы их не закешировали).
Если Node.js старой версии Скрипты install.sh/install.bat сами проверяют версию и подскажут, что делать, если она младше 22.5.

Атлас островов

Текстовый вики-каталог всех островов текущего проекта — открывается кнопкой «📖 Атлас островов» в шапке. Список автоматически группируется:

  1. по фракции — Империя / Лига / Эльфийские / Нейтральные / Другие;
  2. внутри каждой фракции — по размеру острова, от архипелагов до малых аллодов.

Клик по названию острова открывает его страницу — ту же самую, что открывается с глобальной карты.

Переназначить остров в другой проект можно в редакторе на странице острова — блок «Проект» в сайдбаре.

Страница острова

Открывается кликом по метке на карте или ссылке в вики-каталоге. Содержит:

  • Описание и историю — свободный текст;
  • Галерею с подписями к фото — клик по фото открывает полноэкранный просмотр (лайтбокс) со стрелками и клавиатурой;
  • Локации — инлайн-блоки прямо на странице острова, у каждой своё описание и своя галерея;
  • Мини-карту локаций — если у острова есть карта-подложка (поле «есть» в сведениях), локации можно расставить по ней визуально;
  • Похожие острова — того же архипелага или категории;
  • Сведения (владелец, архипелаг, дополнение, сюжет) — пустые поля просто скрываются, а не показываются прочерком.

Вход и права Редактор / Администратор

Без входа сайт полностью доступен только для чтения — ничего нельзя кликнуть на редактирование. Есть два уровня доступа для вошедших:

РольМожет
РедакторПравить контент: острова, локации, галерею, рисование на карте, фракции, украшения. Не видит «⚙ Настройки» и «О системе».
АдминистраторВсё то же плюс настройки сайта (название, логотип, тема, цвет), бэкапы (скачать/восстановить), импорт (полная замена базы), управление пользователями, вкладка «О системе».
  1. Нажмите «Войти» в шапке.
  2. Сервер сам создаёт дефолтный аккаунт admin / admin0000 при самом первом запуске (если на сервере ещё нет вообще ни одного пользователя) — войдите с этими данными.
  3. При следующих входах — вводите своё имя пользователя и пароль.
  4. Нажмите «Редактор», чтобы включить режим правки (доступно и редактору, и администратору).

Обязательная смена пароля. При первом входе дефолтным admin/admin0000 — а также при первом входе на любой аккаунт, который для вас завёл администратор, — сайт сразу покажет форму смены пароля поверх всего интерфейса, без кнопки «отмена». Продолжить работу, не сменив пароль, нельзя.

Аккаунты — многопользовательские, но приглашать новых может только администратор, через «⚙ Настройки» → «👤 Пользователи» — там же выбирается роль нового аккаунта (по умолчанию «редактор»). Нельзя удалить последний оставшийся аккаунт вообще и нельзя удалить последнего оставшегося администратора — иначе сайт остался бы либо совсем без входа, либо без единого способа управлять настройками. Удалить конкретного администратора (в том числе исходный дефолтный admin) можно свободно, пока в системе остаётся хотя бы один другой администратор.

Забыли все пароли, или нужно удалить чужой аккаунт без доступа к сайту? Остановите сервер и выполните npm run reset-password в папке server/ — команда покажет список аккаунтов и даст удалить конкретный (по имени) либо все сразу. При полном сбросе — при следующем запуске сервер снова сам создаст дефолтный admin / admin0000 (с требованием сразу сменить пароль), данные островов при этом не пострадают.

Редактирование текста

В режиме редактора кликните по названию, описанию или истории острова — текст становится редактируемым прямо на странице. Уход с поля (клик в другое место) сохраняет правку автоматически.

После сохранения внизу экрана на несколько секунд появляется уведомление с кнопкой «Отменить» — она откатывает именно это изменение, и на странице, и на сервере.

Галерея и подписи

Кнопка «+» в галерее острова или локации предлагает выбор:

  • Файл с компьютера — загружается на сервер; крупные фото автоматически уменьшаются и сжимаются, чтобы не раздувать диск;
  • Ссылка (URL) — просто указывается адрес изображения.

Под каждым фото в режиме редактора можно кликнуть и вписать подпись — она видна и в галерее, и в полноэкранном просмотре.

Локации и мини-карта

Кнопка «+ Добавить локацию» создаёт новый блок прямо на странице острова. Блоки можно переставлять местами — зажмите ручку ⠿ слева от названия локации и перетащите (работает и мышью, и пальцем).

Если у острова включено «Карта локации» и загружена картинка-подложка, ниже появляется мини-карта: локации из списка неразмещённых можно перетащить прямо на неё, а уже размещённые — двигать, чтобы уточнить позицию.

Расстановка островов на глобальной карте

В режиме редактора слева появляется панель «Неразмещённые острова». Перетащите остров из списка на нужное место на карте — сработает и мышью, и пальцем на тач-экране. Уже размещённую метку можно взять и переместить точно так же.

Новый остров

Кнопка «+ Новый остров» вверху той же панели создаёт пустую карточку острова (только с названием) и сразу открывает её страницу — дальше остров заполняется как обычно и появляется в списке неразмещённых, пока его не перетащат на карту.

Удаление острова

На странице острова в режиме редактора справа вверху — кнопка «✕ Удалить остров». Она безвозвратно удаляет остров целиком, вместе со всеми его локациями и галереей (включая файлы в uploads/). Действие требует подтверждения и не имеет отмены — если нужна подстраховка, сначала сделайте экспорт или бэкап (см. раздел «Бэкап и восстановление»).

Фракция, категория, климат, размер, архипелаг

В режиме редактора эти теги на странице острова кликабельны для редактирования (вне редактора клик по ним, как обычно, фильтрует карту/вики). Появляется список уже использующихся в базе значений — можно выбрать номер существующего (чтобы случайно не завести дубликат вроде «Империя» и «имперский» как разные фракции) либо вписать новое. Пустое поле показывает призрачную кнопку «+ фракцию» и т.п. — так его можно завести впервые.

Поля «Владелец», «Тип», «Дополнение» и «Сюжет» в сайдбаре редактируются так же кликом, но без списка вариантов — это обычные текстовые заметки.

Рисование на карте

В режиме редактора справа на карте появляется кнопка «🖌» — по клику открывается панель с инструментами: текст, линия, стрелка, прямоугольник, круг, многоугольник, линия от руки, украшение (готовая картинка) и «✕» (стереть). Панель показывается только на самой карте — на других вкладках не мешает.

Выберите инструмент, затем на карте: для текста — кликните в нужном месте и введите подпись; для линии/стрелки/прямоугольника/круга — потяните мышью или пальцем от начальной точки до конечной; для линии от руки — зажмите и ведите мышью, отпустите, чтобы завершить; для многоугольника — кликайте точки одну за другой, двойной клик или Enter завершает фигуру (нужно минимум 3 точки), Esc отменяет черновик; для украшения — сначала выберите картинку в открывшейся панели слева, затем кликните на карте, куда её поставить (можно ставить несколько раз подряд, картинка остаётся выбранной). Чтобы удалить пометку — любую, включая украшение — включите инструмент «✕» и кликните по ней (потребуется подтверждение).

Толщина линии и прозрачность настраиваются отдельными ползунками в панели (применяются к следующей нарисованной фигуре, не к уже существующим). Кнопка «👁 Пометки» скрывает/показывает сразу весь слой пометок на карте — удобно, чтобы посмотреть карту «чисто».

Отмена действия: кнопка «↩ Отменить» в панели или сочетание Ctrl+Z (Cmd+Z на Mac) откатывает последнее создание, удаление или перемещение пометки — по одному шагу за раз, до 50 последних действий. История живёт только в текущей вкладке браузера и не сохраняется при перезагрузке страницы.

Когда ни один инструмент рисования не выбран, курсор над уже поставленной пометкой меняется на «переместить» — её можно взять и перетащить мышью на новое место, новые координаты сохраняются сразу.

Все пометки — векторные SVG-объекты в тех же координатах, что и метки островов, и панорамируются/масштабируются вместе с картой без единого пересчёта вручную — текст не «уплывает» и не размывается при зуме, в отличие от растровой картинки поверх карты. Пометки привязаны к текущему выбранному проекту (Аллоды Онлайн/Пираты/...) — переключение проекта покажет пометки именно этого раздела.

Библиотека украшений

Набор картинок для инструмента «Украшение» — не зашит в код. Стартовый набор (астральные обломки, аномалии, турели и т.п.) идёт в комплекте, а добавлять свои или убирать ненужные можно в «⚙ Настройки» → «🖼 Украшения карты»: название + файл картинки. Удаление украшения из библиотеки не убирает уже расставленные на карте копии — только сам пункт из панели выбора при рисовании новых.

Иконки фракций

Каждой фракции можно назначить свою иконку — она появляется рядом с тегом фракции на странице острова и в заголовке группы в «Атласе островов», если название фракции у острова совпадает с одним из названий в библиотеке (без учёта регистра). Стартовый набор — расы Аллодов Онлайн (Кания, Гиберлинги, Орки, Эльфы и т.д.), но список полностью управляемый, не зашит в код.

Управление — «⚙ Настройки» → «🛡 Иконки фракций»: кликните по картинке, чтобы заменить её файлом; отредактируйте текстовое поле, чтобы переименовать (на какую фракцию иконка назначена); «✕», чтобы убрать запись целиком. Внизу — форма добавления новой.

«Пинг» острова на карте

Когда вы возвращаетесь на глобальную карту со страницы острова (кнопкой «Атлас» или хлебной крошкой) — например, открыв остров из «Атласа островов» и вернувшись обратно — его маркер на карте моргает и от него расходятся кольца, чтобы сразу было видно, где именно он находится. Работает только для островов, уже размещённых на карте.

Иконки островов

По умолчанию каждый остров на карте отмечен шаблонной иконкой-«блобом»: форма зависит от размера острова, цвет — от климата. В сайдбаре страницы острова (блок «Иконка на карте») можно в любой момент заменить заготовку на свою — файлом или ссылкой — и вернуть обратно при необходимости.

Бэкап и восстановление

Меню «💾 Данные» в «⚙ Настройки» (доступно только администратору — см. «Вход и права» выше):

Пункт менюЧто делает
Экспорт (JSON)Скачивает содержимое всех таблиц одним файлом — быстрый просмотровый бэкап.
Импорт (JSON)Заменяет содержимое базы данными из выбранного файла.
Скачать базу целиком (.db)Настоящий файл SQLite — надёжно, но без загруженных файлов (иконок, галереи). Подходит для быстрого локального снимка на той же машине.
Восстановить базу из файла (.db)Заменяет текущую базу целиком. После этого сервер нужно перезапустить вручную.

Для переноса на другой сервер используйте отдельный блок «📦 Полный архив сайта» ниже в тех же настройках — это единственный способ, который переносит вообще всё:

Пункт менюЧто делает
Скачать полный архив (.zip)База и все файлы из uploads/ (иконки островов, галерея, украшения, логотип) одним архивом.
Восстановить из полного архива (.zip)Полностью заменяет и базу, и содержимое uploads/ — файлы, которых нет в архиве, удаляются. Снимок текущего состояния сохраняется в backups/ на всякий случай. После восстановления сервер нужно перезапустить вручную.

Просто «Скачать базу» без файлов — для переезда не годится: ссылки на картинки в базе останутся указывать на файлы, которых на новом сервере физически нет.

Резервную копию базы (без файлов) можно снять и из командной строки, без браузера:

cd server
npm run backup

Копия с меткой времени появится в папке backups/.

Импорт / экспорт

Формат JSON-экспорта — массив островов, каждый со своими локациями и галереей. Экспорт доступен без входа (это просто данные, видимые на сайте и так), импорт — только администратору: он полностью заменяет текущее содержимое базы, так что перед импортом стоит сначала сделать собственный экспорт «на всякий случай».

О системе

Внизу страницы всегда видна мини-плашка (версия, лицензия со ссылкой на скачивание, автор и ссылка на GitHub-репозиторий) — доступна вообще всем посетителям, без входа. Клик по номеру версии открывает полную вкладку «О системе» — но только администратору; всем остальным (или незалогиненным) покажет всплывающее сообщение, что нужны права администратора.

Полная вкладка показывает живое состояние сервера: окружение (Node.js, платформа, время работы, память процесса, PID, размер базы, время последнего бэкапа), список технологий, таблицу зависимостей с кнопкой «Проверить обновления» (сверяет установленные версии с npm registry) и раздел «Последние изменения» — он подтягивается из CHANGELOG.md в корне репозитория, отдельного текста в коде для этого нет. Там же — кнопка скачивания текстового файла лицензии.

Безопасность

  • Секрет сессии генерируется случайно при первом запуске и хранится в файле server/.session-secret — не публикуйте и не коммитьте его (в Docker-режиме вместо файла используется переменная окружения SESSION_SECRET, см. ниже).
  • Сессии хранятся в той же SQLite-базе, а не в памяти процесса — вход не слетает при перезапуске сервера.
  • Пароль — не короче 8 символов. Проверка пароля идёт через асинхронный crypto.scrypt — не блокирует сервер целиком на время хэширования, даже если логинятся несколько человек одновременно.
  • Аккаунты — многопользовательские, с ролями «редактор»/«администратор» (см. «Вход и права» выше); управляются через «⚙ Настройки» → «👤 Пользователи», доступно только администратору. Последний оставшийся аккаунт и последний оставшийся администратор через сайт удалить нельзя.
  • При входе ID сессии пересоздаётся заново (защита от session fixation).
  • После 5 неверных попыток входа IP блокируется на 5 минут.
  • Сервер отдаёт security-заголовки (helmet): строгий Content-Security-Policy без inline-скриптов, X-Content-Type-Options и т.д.; при работе по HTTPS дополнительно включается HSTS.
  • Загружаемые изображения проверяются по реальным байтам содержимого, а не только по заголовку — файл с поддельным расширением будет отклонён.
  • Загружаемые SVG дополнительно очищаются от <script> и обработчиков вида onload="..." (через DOMPurify) — открыть такой файл напрямую по ссылке безопасно.
  • При удалении картинки из галереи файл действительно удаляется с диска — мусор не копится. То же самое происходит при удалении острова целиком — все его локации, галерея и файлы удаляются вместе с ним.

Docker и HTTPS

Для локальной работы одним человеком Docker не нужен — обычный start.sh/start.bat работает без изменений и без TLS. Просто попробовать Docker-режим на своей машине, без домена и HTTPS: docker compose -f docker-compose.local.yml up -d --build, затем откройте http://localhost:4173.

Если же нужно открыть Атлас с других устройств или из интернета, в репозитории есть готовый docker-compose.yml: он поднимает сам сервер и Caddy перед ним, который сам получает и продлевает HTTPS-сертификат Let's Encrypt.

cp .env.example .env
# впишите SESSION_SECRET (openssl rand -hex 48) и ATLAS_DOMAIN
docker compose up -d --build

База, загруженные картинки и бэкапы живут в именованных Docker-томах и переживают пересборку образа. Подробности — в README.md корня репозитория, раздел «Docker-режим».

Команды CLI

Выполняются из папки server/:

npm start              # запустить сервер
npm run backup          # снять резервную копию базы
npm run reset-password  # удалить один или все аккаунты редакторов (сервер должен быть остановлен)

Устройство проекта

Бэкенд — Node.js + Express + встроенный node:sqlite, без нативной компиляции. Фронтенд — обычный HTML/CSS/JS без сборщика, разбит на независимые модули (карта, страница острова, вики-каталог, авторизация и т.д.). Подробная карта файлов — в README.md корня репозитория.
