# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Версии — по внутренней схеме `vYYwWW-NN` (год-неделя-сборка).

Этот файл — единственный источник истины для истории изменений: раздел
«Последние изменения» на странице «О системе» (видна только вошедшим)
парсит именно его (`server/routes/system.js`), отдельного дублирующего
списка в коде нет.

**Каждый значимый коммит должен добавлять сюда запись.** Pre-commit хук
(`scripts/hooks/pre-commit`, ставится через `npm install` в `server/` →
`prepare`) напоминает об этом, если меняются файлы в `server/`,
`public/js/` или `public/*.html`, а `CHANGELOG.md` в этом же коммите не
тронут.

## [Unreleased]

### Добавлено
- Публичная мини-плашка внизу страницы (лицензия, автор, ссылка на GitHub,
  номер версии) — видна вообще всем посетителям, не только вошедшим. Новый
  публичный роут `GET /api/system/public` (без `requireAdmin`) отдаёт
  только безопасный минимум: версию, автора и ссылку на репозиторий
  (парсятся из `package.json.repository.url`, не хардкожены отдельно).
- Отдельная кнопка-переключатель для панели рисования (`🖌`) — раньше
  панель появлялась автоматически при включении режима редактора, теперь
  включается/выключается независимо.
- Инструмент рисования расширен: стрелка, многоугольник (клик за кликом,
  двойной клик/Enter — завершить, Esc — отмена), линия от руки (drag,
  до 500 точек с прореживанием по минимальному расстоянию). Настройка
  толщины линии и прозрачности отдельными слайдерами (раньше — только
  цвет). Переключатель «показать/скрыть все пометки» одной кнопкой. Отмена
  последнего действия — кнопка и Ctrl+Z (создание/удаление/перемещение,
  стек на 50 действий, живёт в памяти вкладки, не переживает перезагрузку).
  Новая колонка `points` (JSON) в `map_annotations` — ADD COLUMN без
  пересоздания таблицы, т.к. на неё не распространялось старое
  CHECK-ограничение; протестировано и на схеме с `icon_url` без ролей,
  и вручную на старом дампе.
- Полный архив сайта: `GET /api/backup/download-full` /
  `POST /api/backup/restore-full` — база **и** все загруженные файлы
  (`uploads/`) одним `.zip`, не только `.db`. Раньше `restore` тащил
  только базу — ссылки в ней на `/uploads/xxx.jpg` после переезда на
  новую машину указывали в никуда. Новая зависимость `adm-zip` (0
  транзитивных зависимостей, чистый JS, без нативных биндингов — не
  усложняет Docker-сборку). Защита от zip-slip (путь `../` внутри архива
  не может выйти за пределы `uploads/`) — проверена не только логикой, но
  и намеренно сконструированным вредоносным архивом. При восстановлении
  снимок текущего состояния (БД + uploads) делается тем же способом, что
  и в обычном restore — «на всякий случай».

### Изменено
- «О системе» была модальным окном — теперь полноценная вкладка
  (`state.view = 'about'`), тот же паттерн, что у «Настройки». Клик по
  номеру версии в публичной плашке открывает её — только для `admin`,
  остальным (или незалогиненным) — тост с объяснением.
- Панель рисования (`#drawToolbar`) раньше показывалась на ЛЮБОЙ вкладке в
  режиме редактора (не только на карте — видимость управлялась только
  `body.editor-on` в CSS, без проверки текущего вида), и висела слева,
  перекрывая список неразмещённых островов. Теперь видимость полностью на
  JS (`updateDrawToolbarVisibility()`, вызывается везде, где переключаются
  вкладки) — показывается только на карте, и перенесена на правую сторону.

## [v26w31-12] — 2026-08-15

### Добавлено
- Ролевая модель: `editor` (полный доступ к контенту) и `admin` (плюс
  настройки, бэкапы, пользователи, «О системе»). Просмотр без логина
  остаётся как был — read-only. Первый аккаунт на сервере всегда `admin`
  (и при бутстрапе с нуля, и при миграции со старых схем без ролей —
  проверено тестами). Приглашать новых пользователей может только `admin`.
- `server/scripts/sync-version.js` — VERSION в корне репозитория стал
  единственным источником правды по версии, скрипт (`npm run version:sync`)
  переносит её в `server/package.json` и `doc/index.html`, чтобы три места
  не расходились друг с другом.

### Изменено
- `doc/index.html` приведена в соответствие: описание ролей вместо
  устаревшего «все редакторы равноправны», уточнено, что бэкапы/импорт/
  «О системе» теперь только для `admin`, добавлена не задокументированная
  ранее секция «О системе», описано перетаскивание уже размещённых фигур
  на карте.

## [v26w31-11] — 2026-08-15

### Добавлено
- Вкладка «О системе»: живое окружение (Node.js, платформа, время работы,
  память процесса, PID, размер БД, время последнего бэкапа), список
  технологий, таблица зависимостей с кнопкой «Проверить обновления»
  (сверка с npm registry), раздел «Последние изменения» из этого файла.
- Красивый баннер в консоли при старте сервера.
- Скачиваемый текстовый файл лицензии: MIT покрывает только код, ресурсы
  Allods Online — собственность ASTRUM ENTERTAINMENT / ASTRUM LAB LLC.
- Перетаскивание уже размещённых фигур на карте мышью (было — только
  создание, редактирования не было вообще).
- Git pre-commit хук + `npm install` автоустановка — напоминает дописать
  CHANGELOG.md, если код поменялся, а он — нет.

### Изменено
- **Вкладка «О системе» закрыта за логином** — теперь часть админ-панели,
  не видна анонимным посетителям публичной вики.
- CSP `img-src` разрешает `https:` — внешние ссылки на иконку/галерею/карту
  локации были нерабочими из-за политики безопасности.
- `crypto.scryptSync` → асинхронный `crypto.scrypt` — синхронная версия
  блокировала весь event loop при параллельных логинах.
- `dompurify` обновлён (умеренная XSS-уязвимость по `npm audit`).
- Добавлено пересоздание ID сессии при логине (защита от session fixation).

### Исправлено
- Инструменты рисования (круг/квадрат/линия) почти не кликались для
  удаления — хитбокс покрывал только тонкую обводку, не всю фигуру.
- Async-роуты (`register`/`login`/`password`/`check-updates`) не были
  обёрнуты в try/catch — необработанный reject валил весь процесс
  (Express 4 не ловит его автоматически, в отличие от Express 5).
- `VERSION` и `CHANGELOG.md` не копировались в Docker-образ — версия в
  контейнере тихо падала на fallback вместо реальной.
